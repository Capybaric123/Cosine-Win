# Cosine-Win

---

A proper Windows version of so-called **_Cosine Engine_**, made specifically because most game engines are built on Windows.

For anyone wanting to contribute, first of all why? And second of all, sure just make a fork add your implementation, and finally make a PR, I will probably accept it without even reading it.
